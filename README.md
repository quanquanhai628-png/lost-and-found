# Lost and found

인터렉티브디자인（2） · 인터랙티브 메모 웹사이트

## 콘셉트
떠다니는 눈물에 기억을 담고, 다시 열어 잊고 있던 내용을 발견하는 메모 웹사이트입니다. 중국 드라마에서 보았던 공중에 떠 있는 눈물과 이를 병에 모으는 장면에서 아이디어를 얻었습니다.

## 사용 방법
- **새 메모**: 빈 공간을 길게 누른 뒤 내용을 입력하고 Save를 누릅니다.
- **읽기·수정**: 물방울을 누르면 내용이 열립니다. 연필 버튼으로 수정할 수 있습니다.
- **중요도**: 별 1·2·3개로 설정합니다. 중요할수록 위쪽에 배치됩니다.
- **이동**: 물방울을 드래그합니다. 컴퓨터에서는 마우스 휠로 크기를 조절할 수 있습니다.
- **보관·찾기**: 메모의 화살표 버튼으로 보관하고, 보관함에서 다시 꺼냅니다.
- **삭제**: 물방울을 길게 누른 뒤 손을 떼고 Delete를 누릅니다.

## 실행
index.html을 브라우저로 열면 실행됩니다. 설치할 프로그램이나 외부 라이브러리가 없습니다.

## 저장
메모는 사용하는 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동으로 동기화되지 않으며, 브라우저의 사이트 데이터를 삭제하면 메모도 사라집니다.
